## 🚀 Cómo Ejecutar el Proyecto

1. Clona el repositorio:
```bash
git clone [URL-del-repositorio]
```

2. Navega al directorio del proyecto:
```bash
cd TIFC2DEV-SDPF6-Simulacion-de-Proyecto-SCRUM_V2
```

3. Abre el archivo `index.html` en tu navegador web preferido

No requiere instalación de dependencias ni servidor web, ya que utiliza CDN para las librerías externas.

## 📝 Descripción del Proyecto

Este sitio web presenta información completa sobre la Feria de las Flores de Medellín, incluyendo:

- **Historia y Tradiciones**: Origen y significado cultural de la feria
- **Eventos Principales**: Desfile de Silleteros, conciertos, autos clásicos
- **Programación Detallada**: Fechas, horarios y ubicaciones de eventos
- **Noticias**: Artículos sobre actividades y novedades
- **Gastronomía**: Información sobre comida típica antioqueña
- **Contacto**: Formulario para consultas y ubicación en mapa

## 🎨 Diseño

El diseño utiliza una paleta de colores inspirada en las flores y la cultura antioqueña, con tonos amarillos, naranjas y verdes que representan la alegría y tradición de la feria.
